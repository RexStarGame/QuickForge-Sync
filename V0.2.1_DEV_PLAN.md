## 3. Optional Authenticator Lock

User-facing name:

- Two-step vault unlock
- Authenticator Lock

Do not call it only “Google Authenticator,” because it should work with authenticator apps generally.

Flow:

1. User clicks Continue with Google.
2. User enters vault code.
3. If Authenticator Lock is enabled, user enters 6-digit authenticator code.
4. Vault opens.

Setup flow:

1. Settings
2. Security
3. Enable Authenticator Lock
4. Show QR code
5. User scans QR with authenticator app
6. User enters 6-digit code to confirm
7. QuickForge saves the setting encrypted inside the vault
8. Authenticator Lock is enabled

Safety rules:

- Optional, never forced
- Only enable from a trusted device
- Require vault code before enabling
- Require valid 6-digit code before enabling
- Show recovery warning before enabling
- Disable requires vault code + authenticator code
- Recovery key path must be clear and tested

Warning text:

If you lose your authenticator app and recovery key, you may lose access to your vault.
